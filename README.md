# Index Prescript

림버스 컴퍼니에 나오는 뤼엔(Rien)의 무기 카두세우스와 지령 단말기를 추가합니다. 비공식 팬메이드입니다.

두 가지 버전이 있어요.

- **Paper 플러그인** (`paper/`): Paper 서버용이에요. 모드 없이 접속할 수 있고, Geyser/Floodgate를 통한 베드락 크로스 플레이도 지원해요. 아래 [Paper 플러그인](#paper-플러그인) 항목을 보세요.
- **Fabric 모드** (저장소 루트): 서버와 클라이언트 모두에 설치하는 모드예요.

기능(카두세우스 형태, 상태 효과, 지령, 대행 헤르메스, Furioso-Replica)은 두 버전이 같습니다.

## Paper 플러그인

- 대상: Paper 26.3, Java 25
- 받는 곳: 저장소의 **Actions** 탭에서 최신 `paper` 실행을 열고, **Artifacts**의 `index-prescript-paper`를 받으세요. 안에 들어 있는 파일은 두 개예요.
  - `index-prescript-paper-0.1.0.jar`: 서버의 `plugins` 폴더에 넣으세요.
  - `index_prescript_pack.zip`: 자바 리소스팩이에요(텍스처와 3D 모델). 플러그인 안에도 들어 있어서 따로 쓰지 않아도 돼요.

### 아이템 받기

```
/indexprescript give caduceus [플레이어]
/indexprescript give terminal [플레이어]
/indexprescript pack        (리소스팩 다시 받기)
```

`/ip`로 줄여 쓸 수 있고, 기본적으로 OP만 쓸 수 있어요. 카두세우스는 철 검, 단말기는 종이를 바탕으로 만든 아이템이에요. 리소스팩이 있으면 전용 모습으로 보입니다.

### 마티아스의 레바테인

```
/indexprescript give laevatein [플레이어]
/indexprescript laevatein <0-3>   (손에 든 레바테인의 해방 단계를 바꾸고 타격 횟수 초기화, 테스트용)
```

해방 안 함(0)과 해방 1~3단계, 모두 네 가지 모습이 있어요. 인벤토리에서는 픽셀 스프라이트로, 손에 들면 3D 모델로 보여요. 네더라이트 검을 바탕으로 만들었어요.

**해방 방법**
1. 레바테인을 오른손에 든 채로 **적을 때리거나, 몹이나 플레이어에게 맞으면** 횟수가 1씩 올라요. 때릴 때는 직전에 센 공격에서 0.5초 이상 지났을 때만 세요. 자바는 공격 쿨다운이 다 차 있어도 세요. 해방 안 함→1단계는 **5번**, 1→2단계는 **7번**, 2→3단계는 **9번**이에요.
2. 지금까지 때린 횟수는 **오른손에 든 레바테인의 개수**로 보여요. 개수가 5, 7, 9가 되면 불붙는 소리가 나고, 칼끝에서 불티가 튀어요. 개수는 표시일 뿐이라, 칼은 언제나 한 자루예요.
3. 그 상태에서 레바테인을 **왼손으로 옮기면** 해방돼요. 자바는 F(양손 바꾸기), 베드락은 인벤토리의 왼손 칸으로 옮기면 돼요. 칼이 자동으로 오른손으로 돌아오고, 주변 6블록 안의 적(앞에 있는 적 우선)을 공격하면서 해방 연출이 시작돼요. 대상은 연출이 끝날 때까지 고정되고, 연출 속 타격마다 피해를 받고 불이 붙어요.

| 단계 | 모습 | 연출 | 총 피해 |
| --- | --- | --- | --- |
| 해방 안 함 | 사슬에 감긴 검은 칼날 | — | — |
| 1단계 | 주황빛 지그재그 날 | 보라 번개 오라 → 회색 휘두르기 2번 → 껍데기가 깨지는 흰 파편 폭발(이때 모습이 바뀜) → 화염 베기 | 19 |
| 2단계 | 넓은 주황 패널 | 화염 초승달 3연타와 폭발 → 거대 폭발(이때 모습이 바뀜) | 24 |
| 3단계 | 가늘고 붉게 빛나는 칼날 | 보라 낙뢰 2번 → 화염 베기 2번 → 초대형 화염 폭발(이때 모습이 바뀜) | 34 |

준비가 안 됐으면 평소처럼 왼손으로 옮겨져요. 준비는 됐는데 주변에 적이 없으면, 왼손에 든 채로 기다리다가 적이 6블록 안에 들어오는 순간 해방돼요. 표의 총 피해는 기본값이고, 아래 패시브 보너스가 더해져요.

**패시브** (레바테인을 오른손에 들고 있을 때. 원작의 "스킬 피격"은 공격을 맞는 것으로, "턴"은 3초로 바꿨어요)

| 패시브 | 효과 |
| --- | --- |
| 잘 봐둬라 딸! (최대 10) | 10으로 시작. 스택당 레바테인 피해 +4%, 2스택마다 +0.5. 공격을 2번 맞을 때마다 1 감소 |
| 중지-원한 (최대 10) | 공격을 2번 맞을 때마다 +1. 스택당 피해 +0.4, 받는 피해 +2%. 최대일 때 받는 피해 +20% 추가 |
| 원한 | 체력이 80%, 60%, 40% 아래로 처음 떨어질 때마다 원한이 최대가 돼요(체력을 90% 이상 회복하면 다시 발동 가능). 원한이 최대일 때 다음 풀차지 공격은 **강력한 공격**(피해 2배, 화염 폭발)이 되고 원한을 모두 소모해요 |
| 초근성 | 해방할 때 얻어요. 받는 피해가 1로 고정. 1단계 6초, 2단계 8초, 3단계 10초 |
| 중지-원한 문신 (최대 3) | 해방 연출 타격마다 +1. 스택당 피해 +10%. 마지막으로 얻고 3초 뒤 사라져요 |
| 앙갚음 장부 | 사용자를 공격한 적에게 30초 동안 표식. 표식이 있는 적을 레바테인으로 때리면 체력 2 회복(1초에 한 번) |

- 원한이 최대일 때는 몸 주변에 붉은 보라 불티가, 초근성이 켜져 있을 때는 금빛 반짝임이 보여요.
- 1분 동안 싸우지 않으면 딸은 10, 원한은 0으로 돌아가요.
- 원작의 정신력 관련 효과는 마인크래프트에 정신력이 없어서 뺐어요. 앙갚음 장부는 정신력 회복 대신 체력을 회복해요.

### 리소스팩 설정 (`plugins/IndexPrescript/config.yml`)

자바 플레이어가 카두세우스와 단말기의 텍스처, 3D 모델을 보려면 리소스팩이 필요해요. 두 가지 방법 중 하나를 고르세요.

1. **플러그인이 직접 제공** (기본값): `host-address`에 플레이어가 접속하는 주소(도메인이나 IP)를 적고, `host-port`(기본 8164) 포트를 열어 주세요. 호스팅 업체를 쓰고 있다면 패널에서 포트를 추가로 할당받아야 할 수 있어요.
2. **외부 주소 사용**: `index_prescript_pack.zip`을 직접 다운로드 링크가 나오는 곳에 올리고, 그 주소를 `url`에 적으세요.

베드락 플레이어(Floodgate)에게는 자바 리소스팩을 보내지 않아요. 베드락에서는 철 검과 종이 모양으로 보이지만, 형태 변환, 지령, 헤르메스, Furioso 같은 기능은 모두 똑같이 동작해요.

### Fabric 모드와 다른 점

- 화면에 뜨는 글자는 **지령뿐**이에요. 형태 이름, 치명타, 흐트러짐, 호흡, 지령 완료, Furioso 타이틀과 TOTAL은 표시하지 않아요. 무기 형태가 바뀌어도 아이템 이름은 그대로예요.
- **지령 리롤**: 단말기를 들고 **웅크린 채 우클릭**하면 지령이 새로 바뀌고, 대신 **나약함 III이 10초** 동안 걸려요. 1초에 한 번만 할 수 있어요.
- "체력이 절반 이하일 때 적을 처치하라" 지령은 없어요.
- 지령 문구는 서버가 각 플레이어의 게임 언어(한국어/영어)에 맞춰 직접 보내요. 베드락에서도 한글이 제대로 보입니다.
- 지령 진행도와 상태 효과는 서버 메모리에만 저장돼요. 대행 헤르메스는 단말기 개수로 저장되기 때문에 서버를 다시 켜도 이어집니다.

- 대상 버전: Minecraft 26.3 / Fabric Loader 0.20.1 / Fabric API 0.165.0+26.3
- 필요 Java: 25 이상

| 아이템 | ID | 설명 |
| --- | --- | --- |
| 카두세우스 | `index_prescript:caduceus` | 사슬이 달린 황동 봉. 공격할 때마다 금속성 액체를 응고시켜 무작위 무기를 만듭니다. |

두 아이템은 크리에이티브 인벤토리의 "전투" 탭에 있어요. 명령어로도 받을 수 있습니다.

```
/give @s index_prescript:rien_terminal
```

## 카두세우스의 형태

공격할 때마다 아래 9가지 중 하나를 무작위로 만듭니다. 같은 형태는 연속으로 나오지 않고, 2초 동안 공격하지 않으면 다시 봉으로 녹아내립니다. 공격 쿨다운이 거의 다 찼을 때(90% 이상)만 새 무기가 형성되고 적중 효과가 발동해요. 연타로 효과를 쌓을 수는 없습니다. (Paper 플러그인은 공격 쿨다운이 없는 베드락을 위해, 직전에 인정된 공격에서 0.5초가 지났을 때도 풀차지로 쳐요.)

각 형태는 원작 스킬의 피해 유형, 코인 피해량 보너스, 적중 효과를 따라 만들었어요. 피해는 풀차지 기준이며, 참고로 네더라이트 검은 8입니다.

| 형태 | 유형 | 피해 | 적중 효과 |
| --- | --- | --- | --- |
| 손도끼 | 타격 | 6~8.8 (들쭉날쭉) | 자신에게 호흡 2, 호흡 횟수 2 |
| 스틸레토 | 관통 | 7 (주변에 다른 적이 있으면 5.25) | 대상에게 침잠 2, 침잠 횟수 2, 구속 3초 |
| 바스타드 소드 | 참격 | 8.1 | 자신의 공격 레벨 +1 (1턴, 최대 2) |
| 레이피어 | 관통 | 7.5 | 대상의 방어 레벨 -1 (1턴, 최대 2) |
| 망치 | 타격 | 8.1 | 흐트러짐 피해 5 |
| 대검 | 참격 | 9.2 + 낙하 거리 (최대 +8) | 대상에게 참격 취약 1 (1턴, 최대 2) |
| 랜스 | 관통 | 8.6 | 관통 취약 1, 앞으로 돌진, 대상 뒤 4블록 일직선의 적에게 50% 피해 |
| 채찍 | 타격 | 7.5 | 타격 취약 1, 출혈(시듦) 4초, 나약함 4초, 자신 쪽으로 끌어당김 |
| 대낫 | 참격 | 8.5, 항상 치명타 (10.1) | — |

### 상태 효과

원작의 "턴"은 3초로 바꿨어요.

- **호흡**: 위력 × 5% 확률로 치명타가 나요(피해 ×1.2). 치명타가 날 때와 턴마다 횟수가 1씩 줄고, 0이 되면 사라집니다.
- **침잠**: 대상이 카두세우스에 맞을 때마다 위력 × 0.5만큼 추가 피해를 받고 횟수가 1 줄어요. 10초 동안 맞지 않으면 사라집니다.
- **흐트러짐**: 흐트러짐 피해가 대상 최대 체력의 절반(최소 10)만큼 쌓이면 1턴 동안 흐트러져요. 흐트러진 대상은 거의 움직이지 못하고, 카두세우스 피해를 1.5배로 받습니다. 쌓인 피해는 10초 뒤 초기화돼요.
- **공격 레벨 증가**: 레벨당 피해 +1.
- **방어 레벨 감소**: 레벨당 받는 피해 +7.5%.
- **참격/관통/타격 취약**: 같은 유형의 공격에 받는 피해가 스택당 +10%.

치명타, 흐트러짐, 호흡 상태는 공격할 때 액션바에 표시됩니다.

## 단말기와 지령

단말기를 **왼손**에 들면 액션바에 지령과 진행도가 표시돼요. 지령은 왼손에 들고 있을 때만 진행됩니다. 새 지령이 들어올 때는 무작위 알파벳과 기호가 한 글자씩 생겨난 뒤, 왼쪽부터 한글로 바뀌어요.

대행 헤르메스 수는 왼손 단말기의 **아이템 개수**로 표시돼요. 9가 되면 단말기가 반짝입니다. 0과 1은 둘 다 개수 숫자가 보이지 않아요. 단말기 개수가 헤르메스를 기억하기 때문에, 서버를 다시 켜도 헤르메스가 이어집니다. 왼손이 아닌 곳의 단말기는 항상 1개로 유지돼요.

| 지령 | 완료 조건 |
| --- | --- |
| 적을 3번 공격하라 | 카두세우스로 풀차지 공격 3번 |
| 망치로 적을 흐트러뜨려라 | 망치로 대상을 흐트러짐 상태로 만들기 |
| 치명타를 2번 성공시켜라 | 카두세우스 치명타 2번 |
| 적 2명을 처치하라 | 처치 2번 |
| 웅크린 채로 적을 공격하라 | 웅크리고 공격 |
| 공중에서 적을 내려쳐라 | 공중에서 공격 |
| 대낫 / 채찍 / 랜스로 … | 해당 형태로 적중 |
| 스틸레토로 적을 2번 찔러라 | 스틸레토로 2번 적중 |
| 체력이 절반 이하일 때 적을 처치하라 | 체력 50% 이하에서 처치 |
| 피해를 입지 않고 적을 3번 공격하라 | 피해를 받으면 진행도가 초기화돼요 |

**전투 중**(최근 10초 안에 공격했거나 공격받았을 때)에 지령을 완료하면 **대행 [헤르메스]**가 1 쌓여요. 최대 9입니다. 완료하면 바로 새 지령이 들어와요.

## Furioso-Replica

대행 헤르메스가 9이고, 단말기를 왼손에, 카두세우스를 오른손에 들고 있으면 주변에 반투명한 검은 아우라가 생겨요. 이 상태에서 카두세우스로 적을 공격하면:

1. 대상이 그 자리에 고정되고, 화면에 "Furioso-Replica"가 떠요. 호흡 3을 얻고 호흡 횟수가 3 늘어납니다.
2. **코인 1~8**: 대상을 가로질러 좌우로 돌진하며 매번 새로 형성한 무기로 베어요. 타격마다 파란 궤적과 흰 별 섬광이 나고, 짝수 번째 타격에는 흰 참격선이 X자로 교차해요. 타격마다 침잠 1 부여와 호흡 1 획득이 번갈아 일어나요.
3. 시작 위치로 물러나면 대상 주변에 파란 고리가 소용돌이칩니다.
4. **코인 9**: 낫으로 고정되고, 치명타 피해 +90%, 침잠 횟수 +3. 거대한 대각 참격 뒤에 화면이 어두워져요.
5. 끝나면 대상에게 화상 5초, 속박(구속 III) 6초, 모든 유형 취약 3이 걸리고, 대행 헤르메스를 전부 소모해요. 이후 1턴 동안은 헤르메스를 얻지 못합니다.

피해: 각 코인은 형성된 무기 피해의 60%(9번째는 100%)에 지령 표식 +10%를 더해요. 여기에 자신의 호흡과 대상의 침잠 합 6당 +25%(최대 +50%)가 붙어요. 액션바에 누적 피해(TOTAL)가 표시됩니다.

인벤토리에서는 픽셀 스프라이트로 보이고, 손에 들면 3D 모델로 보입니다.

## 빌드

GitHub Actions가 푸시할 때마다 빌드합니다. 저장소의 **Actions** 탭에서 최신 `build` 실행을 열고, **Artifacts**에 있는 `index-prescript`를 내려받으세요. 압축을 풀면 나오는 `.jar` 파일을 `mods` 폴더에 넣으면 됩니다. 이 모드와 함께 Fabric API도 설치해야 합니다.

PC에서 직접 빌드하려면 Java 25를 설치한 뒤 `gradle build`를 실행하세요.

## 텍스처와 모델 다시 만들기

텍스처와 3D 모델은 `tools/`의 스크립트로 만듭니다. Python과 Pillow가 필요해요.

```
python3 tools/textures.py src/main/resources/assets/index_prescript
python3 tools/forms.py src/main/resources/assets/index_prescript/textures/item
python3 tools/gen3d.py src/main/resources/assets/index_prescript preview.png
cd tools && python3 laevatein.py ../src/main/resources/assets/index_prescript preview.png
```
