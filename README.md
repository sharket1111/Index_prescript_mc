# Index Prescript

림버스 컴퍼니에 나오는 뤼엔(Rien)의 무기 카두세우스와 지령 단말기를 추가하는 Fabric 모드입니다. 비공식 팬메이드입니다.

- 대상 버전: Minecraft 26.3 / Fabric Loader 0.20.1 / Fabric API 0.165.0+26.3
- 필요 Java: 25 이상

## 추가되는 아이템

| 아이템 | ID | 설명 |
| --- | --- | --- |
| 카두세우스 | `index_prescript:caduceus` | 사슬이 달린 황동 봉. 공격할 때마다 금속성 액체를 응고시켜 무작위 무기를 만듭니다. |
| 뤼엔의 단말기 | `index_prescript:rien_terminal` | 별표 화면이 달린 지령 단말기. 우클릭하면 무작위 지령을 받습니다. 재사용 대기시간은 5초입니다. |

두 아이템은 크리에이티브 인벤토리의 "전투" 탭에 있어요. 명령어로도 받을 수 있습니다.

```
/give @s index_prescript:caduceus
/give @s index_prescript:rien_terminal
```

## 카두세우스의 형태

공격할 때마다 아래 9가지 중 하나를 무작위로 만듭니다. 같은 형태는 연속으로 나오지 않고, 2초 동안 공격하지 않으면 다시 봉으로 녹아내립니다. 공격 쿨다운이 거의 다 찼을 때(90% 이상)만 새 무기가 형성되고 적중 효과가 발동해요. 연타로 효과를 쌓을 수는 없습니다.

각 형태는 원작 스킬의 피해 유형, 코인 피해량 보너스, 적중 효과를 따라 만들었어요. 피해는 풀차지 기준이며, 참고로 네더라이트 검은 8입니다.

| 형태 | 유형 | 피해 | 적중 효과 |
| --- | --- | --- | --- |
| 손도끼 | 타격 | 6~8.8 (들쭉날쭉) | 자신에게 호흡 2, 호흡 횟수 2 |
| 스틸레토 | 관통 | 7 (주변에 다른 적이 있으면 5.25) | 대상에게 침잠 2, 침잠 횟수 2, 구속 3초 |
| 바스타드 소드 | 참격 | 8.1 | 자신의 공격 레벨 +1 (1턴, 최대 2) |
| 레이피어 | 관통 | 7.5 | 대상의 방어 레벨 -1 (1턴, 최대 2) |
| 망치 | 타격 | 8.1 | 흐트러짐 피해 5 |
| 대검 | 참격 | 9.2 + 낙하 거리 (최대 +8) | 대상에게 참격 취약 1 (1턴, 최대 2) |
| 랜스 | 관통 | 8.6 | 관통 취약 1, 앞으로 돌진, 대상 뒤 4블록 일직선의 적에게 50% 피해 |
| 채찍 | 타격 | 7.5 | 타격 취약 1, 출혈(시듦) 4초, 나약함 4초, 자신 쪽으로 끌어당김 |
| 대낫 | 참격 | 8.5, 항상 치명타 (10.1) | — |

### 상태 효과

원작의 "턴"은 3초로 바꿨어요.

- **호흡**: 위력 × 5% 확률로 치명타가 나요(피해 ×1.2). 치명타가 날 때와 턴마다 횟수가 1씩 줄고, 0이 되면 사라집니다.
- **침잠**: 대상이 카두세우스에 맞을 때마다 위력 × 0.5만큼 추가 피해를 받고 횟수가 1 줄어요. 10초 동안 맞지 않으면 사라집니다.
- **흐트러짐**: 흐트러짐 피해가 대상 최대 체력의 절반(최소 10)만큼 쌓이면 1턴 동안 흐트러져요. 흐트러진 대상은 거의 움직이지 못하고, 카두세우스 피해를 1.5배로 받습니다. 쌓인 피해는 10초 뒤 초기화돼요.
- **공격 레벨 증가**: 레벨당 피해 +1.
- **방어 레벨 감소**: 레벨당 받는 피해 +7.5%.
- **참격/관통/타격 취약**: 같은 유형의 공격에 받는 피해가 스택당 +10%.

치명타, 흐트러짐, 호흡 상태는 공격할 때 액션바에 표시됩니다.

인벤토리에서는 픽셀 스프라이트로 보이고, 손에 들면 3D 모델로 보입니다.

## 빌드

GitHub Actions가 푸시할 때마다 빌드합니다. 저장소의 **Actions** 탭에서 최신 `build` 실행을 열고, **Artifacts**에 있는 `index-prescript`를 내려받으세요. 압축을 풀면 나오는 `.jar` 파일을 `mods` 폴더에 넣으면 됩니다. 이 모드와 함께 Fabric API도 설치해야 합니다.

PC에서 직접 빌드하려면 Java 25를 설치한 뒤 `gradle build`를 실행하세요.

## 텍스처와 모델 다시 만들기

텍스처와 3D 모델은 `tools/`의 스크립트로 만듭니다. Python과 Pillow가 필요해요.

```
python3 tools/textures.py src/main/resources/assets/index_prescript
python3 tools/forms.py src/main/resources/assets/index_prescript/textures/item
python3 tools/gen3d.py src/main/resources/assets/index_prescript preview.png
```
