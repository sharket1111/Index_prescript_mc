## 1. 설치와 기본 설정

- **서버:** Paper 26.3, Java 25
- **설치:** 두 jar 파일을 서버의 `plugins` 폴더에 넣고 서버를 다시 켜요.
- **베드락 (Geyser/Floodgate):** 그대로 접속할 수 있어요. IndexPrescript가 베드락용 팩(3D 아이템, 아이콘, 음성)을 Geyser 폴더에 자동으로 넣어 줘요.

### 자바 리소스팩

자바 플레이어가 무기의 3D 모델, 효과 아이콘, 스킬 화면을 보려면 리소스팩이 필요해요. 설정은 `plugins/IndexPrescript/config.yml`에서 해요.

1. **플러그인이 직접 보내기 (기본값):** `host-address`에 서버 접속 주소를 적고 `host-port`(기본 8164) 포트를 열어 주세요. 호스팅 업체를 쓴다면 패널에서 포트를 추가로 받아야 할 수 있어요.
2. **외부 주소 쓰기:** `index_prescript_pack.zip`을 직접 다운로드 링크가 나오는 곳에 올리고, 그 주소를 `url`에 적어요.

리소스팩이 안 받아졌다면 `/ip pack`으로 다시 받을 수 있어요.

## 2. 먼저 알아둘 공통 규칙

| 용어 | 뜻 |
| --- | --- |
| **턴** | 원작의 1턴은 이 서버에서 **7초**예요. "1턴 동안"은 7초 동안이에요. |
| **풀차지 공격** | 공격 쿨다운이 거의 다 찬 공격이에요. 베드락은 쿨다운이 없어서, 직전에 인정된 공격에서 0.5초가 지나면 풀차지로 쳐요. 연타로는 효과가 쌓이지 않아요. |
| **코인 위력** | 원작의 코인 위력 +1은 여기서 **피해 +15%**예요. |
| **연출 카메라** | 큰 스킬을 쓰면 화면이 별도 카메라로 바뀌어 장면을 비추고, 끝나면 원래 시점으로 돌아와요. 내 몸 대신 대역이 움직여요. 베드락은 평소 시점 그대로 내 몸이 움직여요. |
| **스킬 화면** | 스킬을 쓰는 동안 화면 가장자리에 원작의 검은 띠가 나와요. 작은 스킬은 위아래 띠, 큰 스킬은 왼쪽 아래와 오른쪽 위 모서리예요. 큰 스킬은 왼쪽 아래에 **TOTAL**(이번 스킬의 누적 피해)이 떠요. 자바 전용이에요. |

### 상태이상을 마인크래프트 효과로 바꾼 것

| 원작 | 이 서버 |
| --- | --- |
| 화상 | 불 붙음 |
| 출혈 | 시듦 |
| 속박 | 구속 |
| 마비 | 나약함 |
| 흐트러짐 | 구속 + 나약함 X (효과 목록에 "흐트러짐"으로 보여요) |
| 호흡 | 행운 효과 아이콘으로 보여요 (레벨 = 위력) |
| 보존 | 불운 효과 아이콘으로 보여요 (레벨 = 위력, 시간 = 횟수) |
| 망 | 힘 효과 (무기에 금빛 고리가 감겨요) |

### 흐트러짐 (모든 무기 공통)

흐트러짐 피해가 대상 최대 체력의 절반(최소 10)만큼 쌓이면 1턴 동안 흐트러져요.

- 흐트러진 대상은 거의 움직이지 못하고, 근접 공격과 투사체 피해가 0이 돼요.
- 흐트러진 채로 또 흐트러지면 **흐트러짐 → 흐트러짐+ → 흐트러짐++**로 단계가 올라요(구속 IV/VI/VIII).
- 대상 몸 위에 단계 그림과 게이지가 떠요.

### 정신력 (SP)

마인크래프트에는 정신력이 없어서 **체력으로 계산**해요.

- 하트 5칸(체력 10)이 정신력 0이에요. 체력이 가득 차면 45, 0이면 -45예요.
- 정신력을 쓰는 효과는 그만큼 체력이 줄어요.

## 3. 카두세우스와 뤼엔의 단말기

`/ip give caduceus`, `/ip give terminal`로 받아요.

### 카두세우스 (오른손)

풀차지 공격을 할 때마다 아래 9가지 무기 중 하나로 변해요. 같은 무기가 연속으로 나오지 않고, 2초 동안 공격하지 않으면 다시 봉으로 녹아요.

| 무기 | 유형 | 피해 | 맞히면 |
| --- | --- | --- | --- |
| 손도끼 | 타격 | 6~8.8 (들쭉날쭉) | 내게 호흡 2, 호흡 횟수 2 |
| 스틸레토 | 관통 | 7 (주변에 다른 적이 있으면 5.25) | 침잠 2, 침잠 횟수 2, 구속 3초 |
| 바스타드 소드 | 참격 | 8.1 | 내 공격 레벨 +1 (1턴, 최대 2) |
| 레이피어 | 관통 | 7.5 | 대상 방어 레벨 -1 (1턴, 최대 2) |
| 망치 | 타격 | 8.1 | 흐트러짐 피해 5 |
| 대검 | 참격 | 9.2 + 낙하 거리 (최대 +8) | 참격 취약 1 |
| 랜스 | 관통 | 8.6 | 관통 취약 1, 앞으로 돌진, 대상 뒤 4블록 일직선의 적에게 50% 피해 |
| 채찍 | 타격 | 7.5 | 타격 취약 1, 출혈 4초, 나약함 4초, 내 쪽으로 끌어당김 |
| 대낫 | 참격 | 8.5, 항상 치명타 (10.1) | — |

참고로 네더라이트 검은 8이에요.

**효과 설명**
- **호흡:** 위력 × 5% 확률로 치명타(피해 ×1.2). 치명타가 날 때와 턴마다 횟수가 1 줄어요.
- **침잠:** 카두세우스에 맞을 때마다 위력 × 0.5 추가 피해, 횟수 -1.
- **공격 레벨 +1:** 피해 +1. **방어 레벨 -1:** 받는 피해 +7.5%.
- **취약:** 같은 유형 공격에 받는 피해가 스택당 +10%.

**지령 표식:** 카두세우스로 때린 적과 그 주변 6블록의 무작위 적 하나에 파란 꽃 표식이 2턴 동안 붙어요. 표식이 있는 적은 받는 피해가 +20%, 헤르메스 1당 +2.5%(최대 +20%) 늘어요. 헤르메스가 9이면 모든 대상에게 +30%예요.

### 뤼엔의 단말기 (왼손)

왼손에 들면 액션바에 **지령**이 떠요. 지령은 왼손에 들고 있을 때만 진행돼요.

| 지령 예시 | 완료 조건 |
| --- | --- |
| 적을 3번 공격하라 | 카두세우스로 풀차지 공격 3번 |
| 적을 공격해 흐트러뜨려라 | 대상을 흐트러짐 상태로 만들기 |
| 치명타를 2번 성공시켜라 | 카두세우스 치명타 2번 |
| 적 2명을 처치하라 | 처치 2번 |
| 웅크린 채로 / 공중에서 적을 공격하라 | 그 자세로 공격 |
| 대낫 / 채찍 / 랜스로 … | 그 무기로 적중 |
| 스틸레토로 적을 2번 찔러라 | 스틸레토로 2번 적중 |
| 피해를 입지 않고 적을 3번 공격하라 | 피해를 받으면 처음부터 |

- **전투 중**(최근 10초 안에 공격했거나 맞았을 때)에 지령을 끝내면 **대행 [헤르메스]**가 1 쌓여요(최대 9).
- 헤르메스 수는 왼손 단말기의 **아이템 개수**로 보여요. 9가 되면 단말기가 반짝여요. 서버를 다시 켜도 이어져요.
- **웅크리고 우클릭**하면 지령을 새로 받아요. 대신 나약함 III이 10초 걸려요.

### Furioso-Replica (필살기)

**헤르메스 9 + 왼손 단말기 + 오른손 카두세우스**이면 몸 주변에 검은 아우라가 생겨요. 이때 카두세우스로 적을 때리면 발동해요.

- 연출 카메라로 **12.5초** 동안 원작 타이밍대로 진행돼요.
  1. **0.6~6.4초:** 주변 6블록 안의 적들 사이를 가로지르며 매번 새 무기로 8번 베어요. 침잠 1 부여와 호흡 1 획득이 번갈아 일어나요.
  2. **6.8초부터:** 파란 고리가 소용돌이치며 힘을 모아요.
  3. **10.6~10.8초:** 섬광 뒤에 대낫으로 거대한 대각선 일격을 날려요. 치명타 피해 +90%, 침잠 횟수 +3이에요.
- 끝나면 대상에게 화상, 속박, 모든 유형 취약 3이 걸려요. 헤르메스는 모두 써요.
- **심(心) - 뤼엔:** 잃은 체력 15%마다 피해 +5%(최대 5단계), 40%마다 위력 +1(최대 2)이에요.
- **망:** 정신력이 0 이상(하트 5칸 이상)이면 피해 +40%예요. 끝날 때 정신력 20만큼 체력을 써요.
- 주 대상이 죽으면 주변의 다른 적으로 이어서 공격해요.

## 4. 마티아스의 레바테인

`/ip give laevatein`으로 받아요. 네더라이트 검 기반이고 부서지지 않아요.

### 해방 (4단계: 봉인 → 1 → 2 → 완전 해방)

1. 레바테인을 들고 **적을 때리거나 맞으면** 타격 횟수가 1씩 올라요. 횟수는 왼손의 **봉인 해제 아이콘 개수**로 보여요.
2. 필요한 횟수는 봉인→1단계 **5번**, 1→2단계 **7번**, 2→완전 해방 **9번**이에요.
3. 다 차면 불붙는 소리와 함께 아이콘이 반짝여요. 이때 **F 또는 우클릭**하면 주변 6블록의 적을 공격하며 해방 연출이 나와요.

| 단계 | 연출 (원작 타이밍) | 총 피해 |
| --- | --- | --- |
| 1단계 | 5.5초. 회색 휘두르기 2번 → 2.95초에 껍데기가 깨지며 모습이 바뀜 → 화염 베기 | 19 |
| 2단계 | 8.6초. 화염 초승달 연타 → 6.6초에 거대 폭발과 함께 모습이 바뀜 | 24 |
| 완전 해방 | 8.75초. 보라 낙뢰, 화염 베기 → 6.75초에 초대형 화염과 함께 모습이 바뀜 | 34 |

해방한 뒤에는 레바테인으로 때릴 때마다 불이 붙어요(1단계 1초, 2단계 4초, 완전 해방 9초).

### 스킬 (F 또는 우클릭, 타격 스택을 모두 소모)

해방할 만큼 스택이 차지 않았을 때 F/우클릭을 하면 단계별 스킬이 나가요.

| 단계 | 스킬 | 필요 스택 | 길이 | 내용 |
| --- | --- | --- | --- | --- |
| 봉인 | 짓밟기 | 1+ | 2.4초 | 돌진해 두 번 짓밟기. 출혈 |
| 1단계 | 후끈해지지 않나?! | 3+ | 5.5초 | 화염 호 → 찌르기 → 화염 초승달과 폭발. 화상, 속박, 마비 |
| 2단계 | 슬슬 녹아 죽을 차례다 | 5+ | 5.75초 | 분홍 베기 → 화염 호와 찌르기 → 거대 화염 초승달 |
| 완전 해방 | 칼빵[레바테인] | 7+ | 8초 | 5연타, 연출 카메라 |

### 반격 태세 (웅크리고 우클릭)

2초 동안 구속 V와 나약함 V가 걸려요. 그 사이에 맞으면 나쁜 효과와 불이 모두 풀리고 반격해요.

| 반격 | 조건 | 길이 | 내용 |
| --- | --- | --- | --- |
| 규칙 위반 | 기본 | 2.6초 | 회색 호 2번, 출혈, 체력 2 회복. 문신이 이미 있었다면 한 번 더 |
| 즉결처형[레바테인] | 완전 해방 + 스택 8 이상 | 12.5초 | 베기, 발차기, 칼을 던져 꽂고, 드롭킥으로 박아 넣고, 사슬로 회수해 흰 초승달로 마무리 |

- 체력 50% 이하면 스킬 피해 +40%(즉결처형 +60%)예요.
- 2단계부터는 스킬을 쓸 때 나도 불이 붙어요(2단계 1초, 완전 해방 2초).
- 스킬 시전 중에는 대상이 그 자리에 붙잡혀 있어요.

### 패시브 (레바테인을 오른손에 들고 있을 때)

| 패시브 | 효과 |
| --- | --- |
| 잘 봐둬라 딸! (최대 10) | 10에서 시작. 스택당 피해 +4%. 2번 맞을 때마다 1 감소 |
| 중지-원한 (최대 10) | 2번 맞을 때마다 +1. 스택당 피해 +0.4, 받는 피해 +2% |
| 원한 | 체력이 80%, 60%, 40% 아래로 처음 떨어질 때 가득 참. 가득 찬 상태의 다음 풀차지 공격은 피해 2배 + 화염 폭발 |
| 초근성 | 해방할 때 얻음. 받는 피해가 1로 고정 (6/8/10초) |
| 중지-원한 문신 (최대 3) | 해방 연출 타격마다 +1. 스택당 피해 +10% |
| 앙갚음 장부 | 나를 때린 적은 30초 동안 표식. 그 적을 때리면 체력 2 회복 |

1분 동안 싸우지 않으면 스택이 처음으로 돌아가요.

## 5. 르누아르의 망치

`/ip give hammer`로 받아요. 철퇴 기반이지만 검과 같은 공격 속도로 휘둘러요.

### 약속된 못

- 같은 적에게 **낙하 공격이 아닌 일반 풀차지 공격을 3번 연속** 맞히면 하늘에서 노랗게 빛나는 못이 떨어져 박혀요. 3초 안에 이어서 때려야 연속으로 쳐요.
- 한 대상에 최대 **10개**까지 박혀요. 1·2타째에는 금빛 입자가 조금씩 늘어나요.
- **철퇴 낙하 공격**으로 맞히면 못 1개당 피해가 +1 늘고, 그 대상의 못이 모두 사라져요.
- 마지막 못을 박은 뒤 60초가 지나거나 대상이 죽으면 못이 사라져요.

### 검은 신의 목소리

- 망치로 적을 때릴 때마다 **+5**, 최대 **100**이에요.
- 망치를 들고 있으면 **왼손 아이콘의 개수**로 보여요. 50 이상이면 금색이 되고, 100이 되면 반짝이며 소리가 나요.

### 스킬 (적을 바라보고 우클릭, 자바는 F도 가능)

두 스킬 모두 목소리를 **전부** 써요.

| 목소리 | 스킬 | 길이 | 내용 |
| --- | --- | --- | --- |
| **50 이상** | 탄생을 끊으리라 | 6.85초 | 못 2개 낙하(하나는 박힘) → 빛기둥 → 금빛 가로 휘두르기 → 도약 → 큰 망치를 머리 위에서 내려찍어 금빛 먼지 돔 |
| **100** | 거듭 내리쳐, 탄생을 끊으리라 | 9초 | 대상 주변 8블록의 적 전부. 섬광과 못비, 모든 적에게 못 2번 → 휘돌려 치기 → 높이 도약해 얼굴 클로즈업 → 큰 망치를 내려찍어 하얀 폭발 |

- 마지막 일격에서 못이 3개 이상 박힌 적은 못 1개당 피해 +3%(최대 90%)이고, 못은 모두 써요.
- **피해 보너스:** 대상들의 못 합 6개당 +15%(최대 2번), 보존 위력 3 이상이면 +15%('탄생을 끊으리라'는 +40% 추가)예요. '거듭 내리쳐'는 대상이 3명 미만이면 모자란 1명당 +50%예요.

### 보존 (불운 효과 아이콘)

- 효과 목록에 **"보존"**으로 보여요. **레벨이 위력**이고 **시간 10:SS의 SS가 횟수**예요(최대 20).
- 망치를 들고 있는 동안에는 시간이 줄지 않아요.
- 두 스킬의 마지막 타격이 맞으면 보존 횟수 +4예요.
- 못을 박을 때 보존이 12 이상이면 못을 1개 더 박고 4를 써요. 12 미만이면 2를 써요.
- 누적 10을 쓸 때마다 위력 +1이에요(최대 10).

**테스트:** `/ip renoir 100 20`을 입력하면 목소리 100, 보존 20이 돼요. 바로 큰 스킬을 써볼 수 있어요. 작은 스킬은 `/ip renoir 50`이에요.

## 6. 검은 신 모드

`/ip blackgod`을 입력하거나, `/ip give blackgod`으로 받은 아이템을 우클릭해서 켜고 꺼요.

### 켜고 끄기

- **켜면:** 인벤토리 전체(갑옷, 왼손 포함)가 보관되고 비워져요. 몸은 투명해지고, 3D 로브와 후광이 몸에 붙어요.
  - 본인 화면에서는 로브와 후광이 보이지 않아요. 1인칭 시야를 가리지 않게 하려고요. 다른 플레이어에게는 보여요.
- **핫바:** 1번 칸은 **검은 신의 망치**(스킬 열기), 9번 칸은 **검은 신 해제**예요.
- **끄면:** 보관한 인벤토리가 돌아와요. 그동안 주운 물건도 그대로 남아요.

### 스킬 쓰기

1. 1번 칸의 망치를 **우클릭**하면 9개 스킬이 핫바에 펼쳐져요.
2. **숫자키**(또는 휠, 베드락은 칸 터치)로 칸을 고르면 그 스킬이 바라보는 적(24블록 안)에게 나가요.

| 1 | 하아…이제 좀 돌아가 주지? | 4.8초 | 4, 4 | 5초 |
| 2 | 퇴근 좀 하자고. | 3.3초 | 5, 6 | 6초 |
| 3 | '심판' | 10.8초 | 4, 4, 7 (잃은 체력만큼 최대 2배) | 8초 |

- 7·8·9번은 큰 스킬 화면과 TOTAL이, 나머지는 작은 스킬 화면이 나와요.

### 부활 (모드를 켤 때마다 2번)

죽을 만큼의 피해를 받으면 피해가 취소돼요. 32블록 안 플레이어들의 화면이 하나의 카메라로 고정되고, 9초짜리 부활 연출 뒤에 체력이 모두 회복돼요.

### 키워드 (화면 위 보스바에 표시)

| 키워드 | 내용 |

**스킬이 하는 일**

| 스킬 | 효과 |
| --- | --- |
| 1번 | 보존 +3, 호흡 |

## 8. 거래 플러그인 (/trade)

`/trade`를 입력하거나 **거래 메뉴 아이템**(서버 상점에서 무료)을 우클릭하면 메뉴가 열려요. 모든 거래는 **거래 전용 다이아**로 해요.

### 메뉴 한눈에 보기

| 메뉴 | 하는 일 |
| --- | --- |
| 다이아 교환 | 일반 다이아몬드 ↔ 거래 전용 다이아를 1:1로 바꿔요. 1~64개씩 또는 전부 |
| 시장 | 모든 판매 물품을 한 화면에서 봐요. 최신순/가격순 정렬, 분류별 보기 |
| 판매자별 구매 | 플레이어를 골라 그 사람의 물품을 봐요 |
| 내 물품 | 팔 물건을 가격을 정해 올려요(1인 최대 18개). 가격 변경, 회수 |
| 삽니다 게시판 | 사고 싶은 물건과 가격을 올려요(1인 최대 10건). 다이아는 미리 맡겨져요. 다른 사람의 주문에 물건을 팔 수도 있어요 |
| 직접 거래 | 접속한 플레이어와 1:1 교환. 아래 설명 참고 |
| 송금 | 거래 전용 다이아를 다른 플레이어에게 보내요 |
| 서버 상점 | 귀환권, 경험치, 땅 같은 물품을 사요 |
| 우편함 | 못 받은 물건과 다이아를 받아요 |
| 내 땅 | 서 있는 청크가 내 땅이면 권한을 정해요 |
| 기록 | 내가 산 것, 판 것의 기록 |
| 공용 보관함 | 서버 모두가 쓰는 54칸 보관함 |
| 그룹 | 그룹 만들기, 그룹원·역할·접두사·할인·웨이포인트 |
| 관리자 | (OP) 물품·주문 관리, 기록 조회, 상점 편집, 보호구역 |

### 사고팔기

- **물건 올리기:** '내 물품'에서 내 인벤토리의 물건을 클릭하고 가격을 정해요. 올린 물건은 시장이 맡아 둬요.
- **사기:** 가격만큼 거래 전용 다이아가 빠지고 물건이 들어와요. 판매자가 접속 중이면 바로, 아니면 우편함으로 돈이 가요.
- **삽니다 주문:** 최대 576개(9묶음), 가격 최대 9999. 누가 주문에 팔면 물건은 주문한 사람에게, 맡긴 다이아는 판 사람에게 가요. 내 주문을 클릭하면 취소되고 다이아가 돌아와요.

### 직접 거래

1. '직접 거래'에서 접속한 플레이어에게 요청을 보내요. 요청은 1분 동안 유효해요.
2. 상대가 수락하면 공용 창이 열려요. 각자 최대 16칸까지 물건을 올려요.
3. 둘 다 **확인**을 누르면 교환돼요. 누가 물건을 바꾸면 양쪽 확인이 풀려서 마지막 순간에 바꿔치기를 할 수 없어요.
4. 창을 닫거나 나가면 올린 물건은 모두 주인에게 돌아가요.

### 우편함

판매 대금, 접속하지 않은 사이의 송금, 채워진 주문, 인벤토리가 가득 찼을 때의 물건이 우편함으로 와요. 접속할 때 우편이 있으면 알려 줘요.

### 서버 상점 (기본 상품)

| 상품 | 가격 | 내용 |
| --- | --- | --- |
| 스폰 귀환권 | 2 | 웅크리고 우클릭하면 내 침대로 돌아가요. 1회용 |
| 커스텀 귀환권 | 4 | 처음 쓰면 지금 위치를 저장하고, 다음에 쓰면 그곳으로 이동한 뒤 사라져요 |
| 경험치 3레벨 | 2 | 바로 경험치를 얻어요 |
| 땅 소유권 | 5 | 지금 서 있는 청크를 내 땅으로 사요 |
| 원격 엔더 상자 | 1 | 어디서든 내 엔더 상자를 한 번 열어요 |
| 거래 메뉴 아이템 | 무료 | 우클릭하면 /trade가 열려요 |
| 그룹 웨이포인트 책 | 무료 | 웅크리고 우클릭하면 웨이포인트 목록 |

- 거래 메뉴 아이템과 웨이포인트 책은 죽어도 떨어지지 않고, 부활하면 다시 생겨요.
- 둘 다 무료라서 조합(신호기, 책장), 모루, 숫돌, 대장장이 작업대, 주민 거래, 거래 메뉴에 쓸 수 없어요.

### 공용 보관함 (54칸)

- 내 인벤토리의 물건을 클릭하면 넣어요. 넣은 물건마다 **누가 가져갈 수 있는지** 정해요.
  - 모두 / 정한 플레이어 / 내 그룹원 / 그룹의 특정 역할 이상
- 넣은 사람과 관리자는 언제든 가져가거나 설정을 바꿀 수 있어요. 쉬프트 클릭하면 바로 꺼내요.
- 여러 명이 동시에 봐도 바뀐 내용이 바로 보여요.

## 9. 그룹

'그룹' 메뉴에서 관리해요.

| 항목 | 내용 |
| --- | --- |
| 만들기 | 거래 전용 다이아 **3개**. 이름은 채팅으로 2~16글자 |
| 가입 수 | 한 사람이 최대 **9개** 그룹에 들어갈 수 있어요 |
| 그룹원 수 | 그룹당 최대 **36명** |
| 접두사 | 최대 8글자. 채팅, 탭 목록, 머리 위에 `[접두사]이름`으로 보여요. 내 그룹 중 어느 것을 달지, 또는 안 달지 골라요 |
| 초대 | 초대를 보내면 상대가 '받은 초대'에서 수락하거나 거절해요 |
| 그룹장 넘기기, 나가기, 해체 | 그룹 화면에서 할 수 있어요 |

### 역할과 권한

기본 역할은 **그룹장 > 부대표 > 멤버** 순서예요. 역할을 새로 만들거나 순서를 바꿀 수 있어요(내 역할보다 높게는 못 올려요).

| 권한 | 내용 | 그룹장 | 부대표 | 멤버 |
| --- | --- | :-: | :-: | :-: |
| 초대 | 플레이어 초대 | ✔ | ✔ | |
| 추방 | 나보다 낮은 역할을 내보내기 | ✔ | ✔ | |
| 역할 지정 | 나보다 낮은 그룹원에게 역할 주기 | ✔ | ✔ | |
| 역할 편집 | 나보다 낮은 역할 만들기, 이름·권한 바꾸기, 지우기 | ✔ | | |
| 이름·접두사 | 그룹 이름과 접두사 바꾸기 | ✔ | | |
| 그룹 설정 | 그룹 할인율 정하기 | ✔ | | |
| 그룹원 공격 차단 | 그룹원끼리 서로 공격할 수 없음 | ✔ | ✔ | ✔ |
| 그룹 할인 | 그룹원의 물품을 할인가로 사기 | ✔ | ✔ | ✔ |
| 웨이포인트 사용 | 웨이포인트로 텔레포트 | ✔ | ✔ | ✔ |
| 웨이포인트 좌표 보기 | 좌표 공개 (없으면 비공개) | ✔ | ✔ | |
| 웨이포인트 관리 | 만들기, 이름·위치 바꾸기, 지우기 | ✔ | | |

- **그룹 할인율:** 0~50%. 할인 권한이 있는 그룹원이 다른 그룹원의 물품을 그만큼 싸게 사요. 판매자는 깎인 값을 받아요.

### 그룹 웨이포인트

- 그룹당 최대 **5개**. 만들 때마다 가격이 올라요: **14 → 20 → 30 → 40 → 50** 거래 전용 다이아.
- 관리 권한이 있는 사람이 지금 서 있는 곳에 만들어요.
- 텔레포트는 한 번에 거래 전용 다이아 **1개**예요.
- **웨이포인트 책:** 웅크리고 우클릭하면 내 모든 그룹의 웨이포인트가 그룹별로 한 화면에 나와요. 웨이포인트가 있는 그룹에 속하면 자동으로 받아요.

## 10. 땅과 보호구역

### 내 땅 (청크 단위)

- 서버 상점의 **땅 소유권**(거래 전용 다이아 5개)으로 지금 서 있는 청크(16×16)를 사요.
- 스폰(0,0) 주변 **10청크**, 보호구역, 남의 땅은 살 수 없어요.
- 땅 주인은 뭐든 할 수 있어요. 다른 사람은 주인이 준 권한만 가져요. 누구나 걸어서 들어올 수는 있어요.

**권한 세 가지:** 건축 / 파괴 / 상호작용

| 대상 | 설정 방법 |
| --- | --- |
| 모든 사람 (기본값) | 목록에 없는 모든 플레이어. 처음에는 아무 권한도 없어요 |
| 플레이어별 | 청크당 최대 16명까지 따로 정해요 |
| 그룹별 | 내 그룹의 그룹원 전체, 또는 역할별로 한 번에 정해요 |

- 따로 이름을 정한 플레이어는 그 설정을 따라요. 여러 그룹에 속한 사람은 그중 허용된 것을 모두 가져요.
- '청크 경계 보기'로 10초 동안 경계를 볼 수 있어요.

### 보호구역 (관리자)

관리자가 서 있는 청크를 중심으로 반경 0~10청크를 보호구역으로 정해요. 보호구역에서는 관리자만 건축, 파괴, 상호작용을 할 수 있어요. 이미 있던 플레이어의 땅은 그대로 유지돼요.

## 11. 관리자 기능과 저장 파일

`/trade` 메뉴의 **관리자** 탭은 `playertrade.admin` 권한(기본 OP)이 있어야 보여요.

| 기능 | 내용 |
| --- | --- |
| 판매 물품 관리 | 아무 물품이나 우클릭으로 내려요. 물건은 판매자의 우편함으로 돌아가요 |
| 주문 관리 | 아무 주문이나 우클릭으로 지우고 다이아를 돌려줘요 |
| 기록 조회 | 모든 거래 기록(최대 5000건) |
| 서버 상점 편집 | 인벤토리의 물건을 클릭해 상품으로 추가하고, 가격을 바꾸거나 지워요 |
| 보호구역 | 위 [보호구역](#보호구역-관리자) 참고 |

### PlayerTrade 저장 파일 (`plugins/PlayerTrade/`)

| 파일 | 내용 |
| --- | --- |
| `listings.yml` | 판매 물품 |
| `orders.yml` | 삽니다 주문 (맡긴 다이아 포함) |
| `history.yml` | 거래 기록 |
| `mail.yml` | 우편함 |
| `groups.yml` | 그룹, 역할, 접두사, 웨이포인트 |
| `land.yml` | 땅과 보호구역 |
| `storage.yml` | 공용 보관함 |
| `shop.yml` | 서버 상점 상품과 가격. 직접 고쳐도 되고, 서버를 켤 때 읽어요 |

`shop.yml` 상품 종류는 `spawn_ticket`, `custom_ticket`, `xp`(`levels`), `land`, `ender_chest`, `trade_menu`, `waypoint_book`, `item`(`material`과 `amount`)이에요.
